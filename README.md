# Blueprint Workshop

**Your weapons. Your builds. Your way.**

Blueprint Workshop is a standalone Windows utility for Tom Clancy's Ghost Recon Breakpoint that allows players to create additional weapon blueprints and independently customize each variant in Gunsmith, including in Immersive Mode.

## Features

- Create multiple variants of the same weapon.
- Assign custom blueprint names.
- Independently customize attachments, optics, and camouflage.
- Search and sort available weapons.
- Add, rename, and delete weapon variants.
- Automatically save variant collections.
- Generate installation packages compatible with S0A Mod Manager.

## Requirements

- 64-bit Windows
- Ghost Recon Breakpoint
- [S0A Mod Manager 3.1.3](https://www.nexusmods.com/ghostreconbreakpoint/mods/2227)
- Pre-Patch and Unlock Everything

## Installation

1. Download Blueprint Workshop from Nexus Mods.
2. Extract the application outside your game directory.
3. Run Blueprint_Workshop.exe.
4. Create your desired weapon variants.
5. Click Build Variants.
6. Install the generated ZIP using S0A Mod Manager with Breakpoint closed.
7. Launch Breakpoint and customize your weapons in Gunsmith.

## Building from Source

The source code and build instructions are provided in this repository for transparency, security review, and further development.

## Current Limitations

- Not all weapons are currently available for duplication.
- New variants begin with default Gunsmith configurations.
- Weapon upgrade levels do not automatically carry over.
- In-game functionality has been verified on Steam.
